How to Use This Mobile Automata Simulator

Basic Operation

  • Enter the initial tape contents and head position
  • Define the transition function (δ) in the format: input,output,direction (one per line)
  • Set accepting words (A) and blank symbol (b)
  • The machine will terminate when it reaches a word with no defined transition in \delta and accept if this word is in A
  • Use the Step button to execute one step of the automaton
  • Use the Steps button to execute 10 steps (or until termination)
  • Use the Reset button to restart with the current configuration

Automatic Fields

The following fields are calculated automatically based on your inputs:

  • Input Size (n): Determined from the length of the input strings in your transition function
  • Input Alphabet (Σ): Derived from the symbols used in your tape and transitions
  • Working Alphabet (Γ): Includes all symbols used in transitions and the input alphabet
  • Terminating Words: Words that have no defined transitions in your function

Troubleshooting

If the animations go out of sync (which can happen when the browser tab is running in the background), simply click the Reset button to realign the visual representation.

Sharing Your Machine

Your transition function (δ), accepting words (A), and blank symbol (b) are saved in your browser's local storage. To share your machine with others, they will need to copy these three values.
